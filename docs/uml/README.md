# UML – Ecommerce_Shop

Mở các file `.puml` bằng plugin PlantUML trong IntelliJ hoặc PlantUML CLI để xuất PNG/SVG.

- `01`: Use Case tổng quan
- `02`: Use Case chi tiết CRUD sản phẩm
- `03`: Use Case chi tiết đặt hàng/giỏ hàng
- `04`: Use Case chi tiết tra cứu
- `05`: Sequence đặt hàng
- `06`: Sequence thêm sản phẩm
- `07`: Kiến trúc phân tầng
- `08`: Sequence cập nhật số lượng/xóa giỏ AJAX

Tài liệu đặc tả chi tiết: `../USE_CASE_SPECIFICATIONS.md`.
Các ảnh trong `../figures/` là sơ đồ minh họa từ Graphviz, không thay thế biểu đồ PlantUML ở đây.
